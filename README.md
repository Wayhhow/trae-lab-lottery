# TRAE 实验室 · 摇号抽奖

黑客松现场百人规模的大屏抽奖应用。基于 matter.js 的真实物理摇号机，球在玻璃罩里被气流吹着翻滚，出球结果由代码预先确定、物理只负责表演。

## 三个环节

| 环节 | 候选池 | 奖品 |
|---|---|---|
| 集赞轮 | 问卷收集的 16 人 | 徽章×2、笔记本×2、马克杯×2、键帽×2、单肩包×2 |
| 现场轮 | 组队名单 100 人 | 徽章×3、笔记本×3、马克杯×3、键帽×3、单肩包×3、渔夫帽×3、平板电脑包×2（压轴） |
| 安慰轮 | 现场轮未中奖者，实时推导 | 贴纸×20 |

## 功能

- **物理摇号机**：matter.js 刚体模拟，胶囊形玻璃罩、可开启闸门、周期性气流；球面名字为离屏预渲染纹理
- **公平性**：中奖者由 `crypto.getRandomValues` 先确定，物理只演既定结果；同一环节内不可重复中奖
- **自动连抽**：按 `A` 全程无人值守抽完一轮（约 8 秒一份）
- **安慰轮快速模式**：一次抽满 20 份，中奖名单实时上墙
- **压轴奖品动效**：抽到平板电脑包前播 3.5 秒 FINAL PRIZE 全屏提示
- **开奖记录**：秒级时间、环节、奖品等级、中奖人；支持一键复制与 CSV 导出
- **持久化**：名单与结果实时写入 localStorage，刷新或意外关闭后可恢复并回到上次所在环节
- **屏保**：60 秒无操作进入跑马灯屏保，任意键唤醒
- **音效**：出球与中奖两类提示音，运行时合成 WAV，无版权与网络依赖

## 快捷键

| 键 | 作用 |
|---|---|
| `空格` | 抽取球体；自动连抽中按它停止 |
| `A` | 自动连抽（集赞轮、现场轮） |
| `→` | 切换至下一环节 |
| `F` | 全屏切换 |
| `M` | 静音切换 |
| `H` | 快捷键说明 |

## 开发

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产物在 dist/
```

技术栈：Vite · React 19 · TypeScript · Tailwind CSS 4 · matter.js · Howler.js

## 部署

推送到 `main` 后由 GitHub Actions 自动构建并发布到 GitHub Pages。
项目页地址：https://wayhhow.github.io/trae-lab-lottery/

> 构建时会自动加上 `/trae-lab-lottery/` 前缀，本地 dev 仍走根路径。
> 路由使用 HashRouter —— GitHub Pages 没有 SPA 回退，哈希路由能保证刷新深层页面不丢。
